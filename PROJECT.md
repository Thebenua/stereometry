# Проект: «Сечения»

## Зачем

Учительнице математики нужна замена GeoGebra-апплетам: там нельзя свободно
строить свои фигуры и двигать точки, а показывать сечения и плоскости на уроке
нужно. Дополнительно — учебный проект для портфолио.

## Состояние на 21.11.2026

Работает и проверено в браузере (1440×1000, 768×1024, 390×844, 320 px):

- все готовые тела, параметры, свободные и «прилипающие» точки M/N/K;
- сечение: площадь, периметр, тип, уравнение плоскости, параллельный сдвиг;
- «что оставить после разреза»: всё тело / верхняя / нижняя половина; вторая часть
  и её подписи скрываются, срез закрашен и заштрихован;
- своя фигура: клик по сетке, выпуклая оболочка, перетаскивание вершин,
  правка координат, удаление, преобразование готовой фигуры в редактируемую;
- PNG с подписями и полями, `.json`, ссылка с состоянием в адресе;
- светлая/тёмная тема, адаптив, горячие клавиши, справка, задачи;
- автономная сборка `dist/secheniya.html` (0,84 МБ, без сети);
- масштаб интерфейса 100 / 125 / 150 % и увеличенные точки под палец — для сенсорных панелей;
- README в стиле Campus Life и 7 широкоформатных иллюстраций в `design/showcase/`.

## Готовность

Готово к показу учителю и опубликовано: репозиторий `Thebenua/stereometry` и GitHub Pages
<https://thebenua.github.io/stereometry/>. Автономный файл `dist/secheniya.html` лежит там же
для скачивания и работает без сети.

## Следующий шаг

1. Показать учительнице <https://thebenua.github.io/stereometry/> (или отдать
   `dist/secheniya.html`), собрать замечания.
2. По желанию: тела вращения и их сечения, наклонные призмы, «раздвинуть» половины
   после разреза, сохранение задач учителем.
4. Отдельно решить с портфолио: в какую из копий личного сайта добавлять кейс.

## Как проверять

```powershell
python -m http.server 8781 --directory D:\work\stereometry
```

Сценарии: выбрать каждое тело → потянуть M по ребру → отпустить в стороне →
включить разрез → сменить половину → «Своя фигура» → «Очистить» → четыре клика
по сетке → потянуть вершину → PNG.
